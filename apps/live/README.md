# Bazzy Live

Live events and streams on the Bazzy TV platform.

- Sign-in: "Sign in with Bazzy TV" (already registered as a sign-in app in `apps/video`)
- Storage: Backblaze B2 bucket `bazzylive`
- Public URL: https://live.bazzy.io (linked from the Bazzy Video header)

Code for Bazzy Live goes in this folder.

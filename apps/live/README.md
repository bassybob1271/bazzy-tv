# Bazzy Live

Live events and streams on the Bazzy TV platform.

The code currently lives in the **`bassybob1271/Stowage`** repo under `apps/live`. `scripts/import-stowage.sh`
moves it here with its full history.

- Sign-in: "Sign in with Bazzy TV" (client `bazzylive`, callback `https://live.bazzy.io/auth/bazzy/callback`)
- Storage: Backblaze B2 bucket `bazzylive`
- Public URL: https://live.bazzy.io
